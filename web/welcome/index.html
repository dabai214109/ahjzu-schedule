常见问题
微信里点了没反应、下载不了？
微信内置浏览器会拦截安装包下载。请点右上角「⋯」→在浏览器中打开，再下载。
提示「未知来源应用」「禁止安装」怎么办？
这是安卓对非应用商店来源的正常拦截。在安装提示里选「仍要安装 / 允许本次安装」；如果没有该选项，去「设置 → 应用管理 → 浏览器 → 安装未知应用」打开权限，再重试。
华为、苹果手机怎么办？
用网页版，免安装。打开后可以把它添加到桌面，用起来和 App 差不多：
· 华为浏览器（官方支持该功能）：点右下角「四个点」→「添加至桌面」；不同版本也可能叫「添加到主屏幕」。
· iPhone / iPad 的 Safari：点「分享」→「添加到主屏幕」。
其他浏览器大同小异，在菜单里找「添加到桌面 / 添加到主屏幕」就行。
课表怎么导进来？
用法二选一（两种方式拿到的东西一样，最后都是粘到「设置 → 导入课表」）：

① 一键抓取书签脚本（推荐，不用开发者工具，和手动抓取类似）
适合电脑（Chrome / Edge / 国产浏览器）和 iPhone / iPad 的 Safari。先打开课表页面，按 Ctrl+Shift+B 显示书签栏，在「设置 → 一键抓取 → 获取」中，把那个蓝色按钮拖到书签栏上，点击此书签 → 抓取 → 复制内容粘贴到输入框 → 导入。

② 手动抓接口响应
在电脑上登录学校系统 → 打开课表查询页 → 按 F12 → Network 中找到 py_kbcx_ew → 右键 py_kbcx_ew 复制为 response/响应，把响应原文粘贴到导入框 → 导入。
怎么更新到新版本？
App 内「设置 → 检查更新」会提示有没有新版本。也可以直接重新下载上面的安装包覆盖安装，课表数据不会丢。

完全免费，无广告，无内购。App 不注册、不上传任何数据，学号密码只在你自己设备上使用。
