一键抓取（书签脚本）

书签脚本是一小段存在你浏览器书签里的代码。在学校课表页面点它一下，会弹出一个小面板：点「抓取」就把当前学期的课表抓出来，复制粘贴到本页即可 —— 不用再按 F12。学期是自动识别的，不用手填；想换学期先在页面上选好再点。

电脑（Chrome / Edge / 国产浏览器）：先打开课表页面，按 Ctrl+Shift+B 显示书签栏，在「设置 → 一键抓取 → 获取」中，把那个蓝色按钮拖到书签栏上，点击此书签 → 抓取 → 复制内容粘贴到输入框 → 导入。

iPhone / iPad（Safari）：先点下面的「点此复制脚本内容」，接着在任意页面点「分享 → 添加书签」建一个书签 → 打开书签列表点「编辑」→ 选中它 → 把地址整段删掉，粘贴刚复制的脚本内容 → 完成。之后按网页登录流程进入学校课表页面，点这个书签即可。

点书签后面板里点「抓取」即可（学期是自动识别的，不用填）；也可以直接点左侧菜单「学生课表查询」，脚本会自动捕获。抓到课表时底部会再弹一个面板，点「复制」，再回到本页粘贴到「导入课表」。

脚本只在你自己的浏览器里运行，学号密码不会被发送到任何第三方。
